Ce site — Portfolio technique SEO/GEO

2026

Projet personnel · hugoogez.fr

Ce portfolio est lui-même un projet technique. Il démontre concrètement la maîtrise du SEO technique et du GEO : zéro framework, HTML5 sémantique, données structurées JSON-LD complètes, architecture pensée pour les moteurs de recherche et les LLMs.

Choix techniques

  • HTML5 sémantique : balises article, section, nav, time, figure — pas de div génériques
  • CSS custom properties uniquement — zéro framework, zéro Google Fonts
  • Données structurées JSON-LD sur chaque page : Person, WebPage, Article, BreadcrumbList, FAQPage
  • Optimisation GEO : résumés denses en tête de page, entités nommées, blocs autonomes
  • Score Lighthouse cible : 90+ sur les quatre axes (performance, accessibilité, bonnes pratiques, SEO)
  • Hébergé sur GitHub Pages — déploiement continu via Git

Technologies

HTML5 CSS JSON-LD Schema.org GitHub Pages SEO technique GEO
